## 修改总结

### 修复的核心 Bug
**标签映射问题**：XGBoost 的 `multi:softprob` 要求类别标签从 0 开始，但原始数据 quality 值为 3-9。原代码未做映射，导致全部 90 次 CV 拟合全部失败。修复方案：

```
quality 3→0, 4→1, 5→2, 6→3, 7→4, 8→5, 9→6
```

### 修改的文件

| 文件 | 操作 | 说明 |
|------|------|------|
| `src/train.py` | **重写** | 修复标签映射 + 36维特征工程 + 样本权重 + 超参数搜索 + 早停 |
| `src/predict.py` | **重写** | 与 train.py 特征工程一致 + 标签逆映射回原始值 |
| `run_log/run.sh` | **更新** | 绝对路径 + 优化输出 |

（未修改 `README.md`、`baseline.md`、`download_wine_data.py`）

### 特征工程（12 → 36 维）

| 类别 | 数量 | 说明 |

| 比例/组合 | 9 | SO₂比率、醇糖比、总酸度等 |

### 模型策略

- **算法**：XGBoost `tree_method=hist, device=cuda`（GPU 加速，NVIDIA H20 96GB）
- **不平衡处理**：`compute_sample_weights()` 反比加权
- **超参数搜索**：`RandomizedSearchCV`（20 次 × 3 折 = 60 次 fit）
- **早停**：最终模型 `early_stopping_rounds=50`，10% 验证集监控
